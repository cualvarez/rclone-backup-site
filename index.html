rclone-backup

A personal backup setup from the owner's computer to the owner's Google Drive.

Purpose

This setup uses local rclone commands to make deterministic backups of selected files to a selected folder in the owner's Google Drive. Copies of deleted or overwritten files are preserved as backup history.

It is for the owner's personal backups, not a public backup-sharing service. This website does not upload, store, or provide access to backup files.

Current status

The setup is being configured. Scheduled backups are not yet confirmed to be running.
